# Monique Poubel — site de advocacia tributária (demonstração)

Site estático responsivo em HTML, CSS e JavaScript puro. Não exige Node, npm, banco de dados ou build. Abra `index.html` para visualizar.

## Publicação no GitHub Pages

1. Crie um repositório novo no GitHub (por exemplo `monique-poubel-site`).
2. Envie **o conteúdo desta pasta**, incluindo `index.html`, `styles.css`, `script.js`, `config.js` e a pasta `assets`, para a raiz do repositório.
3. No repositório, acesse **Settings → Pages → Build and deployment**.
4. Em **Source**, escolha **Deploy from a branch**. Selecione `main` e `/ (root)`, salve.
5. Aguarde a publicação e use o endereço indicado em **Settings → Pages**.

## Ajustes antes de apresentar publicamente

- Edite `config.js` para inserir e-mail profissional, WhatsApp (reservado para integração futura), cidade e número da OAB, após confirmação.
- Substitua a apresentação genérica da profissional por biografia e informações verificadas e aprovadas.
- Confirme quais são as **áreas efetivas de atuação**. As seis áreas atuais são exemplos comuns de advocacia tributária; não se afirma que todas sejam oferecidas pela profissional.
- Revise e valide os três artigos, sobretudo quanto à legislação e à jurisprudência na data de publicação.
- Substitua as ilustrações por fotografias licenciadas ou fotos próprias, caso queira. O site já contém arte local, sem risco de links de imagem externos quebrados.
- O arquivo `assets/logo-original.jpg` conserva a imagem enviada pelo cliente. O cabeçalho usa uma versão recortada da própria imagem enviada. Para melhor nitidez em tamanhos variados, solicite o original vetorial (SVG) à profissional.
- O formulário **não envia dados para um servidor**: depois de configurar o e-mail, usa `mailto:` e exige que o visitante confirme o envio no próprio aplicativo de e-mail. Sem e-mail configurado, ele sinaliza modo demonstração. Para envio direto por formulário, será necessário um serviço de backend compatível e política de privacidade adequada.
- Para produção, defina domínio, política de privacidade e tratamento de dados pessoais, informações de contato e dados profissionais verificados.

## Notas sobre publicidade jurídica

O layout é deliberadamente informativo e não promete resultados, não informa honorários ou descontos e não inventa depoimentos, títulos, vitórias ou tempo de experiência. Consulte as regras aplicáveis de publicidade da OAB antes de publicar: https://www.oab.org.br/leisnormas/legislacao/provimentos/205-2021

## Arquivos

- `index.html`: páginas/seções e metadados.
- `styles.css`: visual, animações 3D suaves e responsividade.
- `script.js`: menu mobile, rolagem, animações, FAQs nativas, artigos e contato.
- `config.js`: configurações a preencher.
- `assets/`: logo original, ícone do site e ilustrações SVG locais.

## Uso

Protótipo de apresentação. Identidade visual do logotipo enviado, sujeita à aprovação da titular. Nenhum dado profissional além do nome foi verificado.
